# TelaJusta

Calculadoras gratuitas de tela para cortinas, manteles y cojines. Sitio estático, sin dependencias, usuarios, analítica ni anuncios activos.

URL prevista: https://ilga25.github.io/telajusta/

## Publicación

GitHub Pages: desplegar desde la rama `main`, carpeta raíz `/`.

## Funcionamiento

`calc.js` contiene las fórmulas; `app.js`, los controles. Las medidas están en centímetros y la compra se redondea hacia arriba a 10 cm. Los cálculos se realizan en el navegador. No incluye corte óptimo, confección especial ni casado horizontal de estampados. Verificar el patrón antes de comprar o cortar.

## SEO y anuncios

Páginas independientes con títulos, descripciones, canonical y marcado WebApplication. Sitemap en `sitemap.xml`. Search Console y AdSense requieren su propia verificación. No se garantiza indexación, tráfico, aprobación publicitaria ni ingresos.
